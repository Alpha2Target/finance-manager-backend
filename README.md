# Finance Manager Backend

A Spring Boot backend application for personal finance management.

## Features

- User Registration & Login
- Category Management
- Transaction Management
- Savings Goals
- Reports & Analytics
- Swagger API Documentation

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Swagger/OpenAPI
- Maven

## API Documentation

Swagger URL:

http://localhost:8080/swagger-ui/index.html

## Database

PostgreSQL

## Run Project

```bash
mvn spring-boot:run
```
